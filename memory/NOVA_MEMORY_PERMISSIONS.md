# NOVA memory permissions

The local session grants the unlocker access to the whole archive. Another tab is refused while that session is active. Import, deletion, backup and restore require direct UI action. Whole-archive deletion requires typing DELETE. Restore authenticates the backup and confirms the merge. Portable backups are private and encrypted.

Future shared access requires authenticated application and device identities, separate Founder-private and approved-shared resources, per-record authorization, expiration and revocation. SENTINEL must enforce current permissions and deny transfers during Emergency Sleep. Family and child applications must be excluded from Founder-private data. Archived approvals never grant operational authority.
