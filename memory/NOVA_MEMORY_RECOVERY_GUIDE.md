# Recover your archive

Open **Backup & Restore**, choose a new backup passphrase, repeat it, then download the encrypted file. Save it to a location you can retrieve later. A bookmarked-only backup is available for smaller transfers. Copy the encrypted file to an SSD using the operating system file manager if desired. Keep multiple encrypted copies, including an offline copy. The application reports when it requests the download. Check that the file exists.

On a replacement device, launch the app, create a local archive, and choose **Verify and restore**. Select the encrypted file and enter its backup passphrase, then confirm the number of conversations to merge. After restoring, compare the totals and open representative records. Existing IDs are skipped as duplicates or conflicts. Backups can be tested using a separate clean browser profile.

The v1 backup contains conversations and their notes, categories and bookmarks. It excludes local history and local security settings. Lost archive and backup passphrases cannot be reset. Copies on other devices and in earlier backup files must be removed independently.
