# NOVA memory roadmap

1. Phase 1 baseline includes local import, review, encrypted storage, library, local search, history, offline shell, backups and restore. Remaining work includes larger backup streaming, incremental snapshots, hardware benchmarking and richer archive conflict management.
2. Phase 2 introduces independently authenticated access for BRAIN 3.0 and PRIME, project views, Founder profile, decision register, separate Private Vault and portable SSD workflows.
3. Phase 3 adds project reconstruction, invention history and structured knowledge with citations, independent evidence and explicit approvals.
4. Phase 4 adds selective encrypted device synchronization, conflict resolution, recovery and revocation.
5. Phase 5 evaluates provider-independent AI retrieval, local semantic search, supported future conversation sharing, and English/Yoruba text and voice access.

Project and invention registries should be populated only from authorized, attributed source material. Verify implementation claims against repository evidence and authorize operational decisions separately.
